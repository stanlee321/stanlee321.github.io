# stanlee321.github.io

Personal site and blog of Stanley Salvatierra — <https://stanlee321.github.io>.
Built by GitHub Pages' own Jekyll: no Actions, no Gemfile, no build step.

**To add a post:** copy `docs/post-template.md` into
`_posts/YYYY-MM-DD-slug.md`, fill in the front matter (`title`, `date`,
`description`, optional `tags` and `image`), write it, then run
`python3 scripts/site_lint.py .` before committing. Pushing to `main` publishes.

**Before writing anything public, read [`CLAUDE.md`](CLAUDE.md)** — the
maintainer guide, with the editorial policy, the post template, the social
workflow, and the review gate. Longer-form docs live in [`docs/`](docs/index.md).

`CLAUDE.md`, `docs/`, `README.md`, and `scripts/` are excluded from the build.
